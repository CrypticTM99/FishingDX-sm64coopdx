# Fishing DX v1.4.0

Created by **CrypticTM** for sm64coopdx.

## Features

- Fish across SM64 stages with rods, bait, shops, and a shared wallet
- Castle Grounds boat opens a stage list (Up/Down, A to travel)
- Custom boat in Dire Dire Docks with a solid deck you can stand on
- Hollowfin mystery fish on Tall Tall Mountain (6% bite chance, hardest fight)
- Hollowfin catch is announced to the whole lobby
- Cancel with B returns your bait; host can /fishing give bait

## Gold rod

actors/pole (pole_geo). Refresh mods so DynOS compiles it.

## Boat

actors/Boat (Boat_geo). Spawns in DDD with collision pads. Also used for the Castle Grounds travel boat.
