# Fishing DX v1.0.0

Created by **CrypticTM** for sm64coopdx.

## Gold rod - pole\_geo

Custom pole at actors/pole/. Loaded with smlua\_model\_util\_get\_id("pole\_geo").
Refresh mods so DynOS compiles it. Falls back to wooden post / metal box if missing.

## Rod upgrade path

Wood → Metal (40) → Gold (100) → Master (200) → Legendary (1500)

## Notes

* Cancel (B) while fishing returns the bait you used on that cast.
* Rare hotspot rotates about every 10 minutes.
* Host: /fishing give <player> <bait> \[amount]

Enjoy fishing with your friends! Works anywhere there is water\*
Some stages may not have custom pools
