Getting Started

## Requirements

| Game - sm64coopdx |
| Mod folder - `fishing-dx` |

## Install

1. Place the `fishing-dx` folder in your mods directory, or drag the mod into the game window.
2. Enable **Fishing DX** in the mods list.
3. Load a save and enter a stage with water (Castle Grounds is a good start).

### Save file locations

| Windows - `%appdata%/sm64coopdx` |
| Linux - `~/.local/share/sm64coopdx` |
| macOS - `~/Library/Application Support/sm64coopdx` |

Mods can live in the base `mods` folder or under `<SAVE FILE LOCATION>/mods`.

## First catch

1. Stand near water in Castle Grounds.
2. Hold **L** to aim the cast marker on the water.
3. Release **L** to cast.
4. Wait for a bite, then use **A** to reel (controls depend on difficulty).
5. On a successful catch Press **B** near the fish to pick it up.

Optional: buy bait at a **Bait Shop** before casting for better luck
